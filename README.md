# IA-SchedExt simulation artifact

Discrete-event simulator, experiments, tests and paper source for *Interference-Aware eBPF Scheduling for
Mixed Serverless Workloads*. **Every number in the paper is generated by this code** (`run_all.sh`).

| Path | Contents |
|---|---|
| `iasched/sim.py` | Simulator and the four policies: EEVDF, Static FaaS Priority, LAVD-like, IA-SchedExt |
| `experiments/run_experiments.py` | Tuning (validation seeds 1000-1007), then E1-E5 on test seeds 0..N-1 |
| `experiments/analyze.py` | Tables (LaTeX), figures, paired statistics, `results/numbers.json` |
| `tests/test_sim.py` | 9 invariant/behaviour tests (`pytest tests`) |
| `bpf/ia_schedext.bpf.c` | **Untested** sched_ext sketch of the policy; not used for any result |
| `paper/` | LaTeX source, generated tables, figures, PDF |

## Model summary (all parameters in `Params`)
4 cores; time in us. FaaS: Poisson arrivals (1,500/s mean; optional on/off burst modulation with the mean
rate preserved), log-normal service (median 0.8 ms, sigma 1.0, clipped to 150 us-12 ms). Background: persistent
CPU-bound daemons, each alternating a 10-50 ms work burst with a 0.5-2 ms sleep. Interference: FaaS service is
inflated by `1 + gamma * (fraction of other cores running background)` (gamma = 0.30) and pays a 40 us cold-cache
penalty when it follows a background task on a core; context switch = 3 us.
EEVDF: global-runqueue approximation (virtual time = mean vruntime, eligibility, earliest virtual deadline,
2.25 ms base slice, run-to-parity: no wake-up preemption of a running task). LAVD-like: EEVDF with deadlines
scaled by a per-thread latency-criticality estimate and criticality-based kick-preemption. It is an
*approximation inspired by* LAVD, not the real scheduler. IA-SchedExt: mode rule from the paper (F thresholds
0.30/0.60, SLO-miss threshold 0.05 over a 100 ms window); AGING-mode constants (boost, alpha, t_gran) are chosen
on validation seeds.

## Assumed (not measured) quantities
Interference strength gamma, cold-cache penalty, context-switch cost, and the IA telemetry/transition costs
(0.2 us per enqueue, 2 us per mode change) are assumptions; the paper reports their sensitivity (E5) but the
"overhead" figure is a *modelled* cost, not a hardware measurement.

## Reproduce
`./run_all.sh`   (or `python experiments/run_experiments.py --quick` for a fast smoke test).
Runs are deterministic given the seed; all policies see identical arrival sequences (common random numbers).

### Windows

From PowerShell, create and activate a virtual environment, then install the
dependencies:

```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

Run the tests and a quick experiment:

```powershell
python -m pytest tests -q
python experiments\run_experiments.py --quick
python experiments\analyze.py
```

The full experiment suite uses more runs and takes longer:

```powershell
python experiments\run_experiments.py
python experiments\analyze.py
```

The generated report is `paper\ia_schedext.pdf`. The `bpf\` source is an
untested Linux `sched_ext` sketch and is not required to reproduce the
simulation results.
